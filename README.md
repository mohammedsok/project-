# Assignment 3 – JavaScript Forms & Data Table

A small multi-page website built with HTML, CSS and JavaScript.

## Pages
- `index.html` – Home page
- `about.html` – Blog / about page
- `contact.html` – Contact form
- `validation.html` – **Part 1:** Registration form (Name, Email, Password, Confirm password, Age) with JavaScript validation. Error messages appear under each field, and the form is blocked until every field is valid.
- `data.html` – **Part 2:** Array of objects rendered as a table with live search and sort buttons (by name / by age).
- `style.css` – Shared stylesheet used by all pages

All pages are linked together through the navigation bar at the top.
